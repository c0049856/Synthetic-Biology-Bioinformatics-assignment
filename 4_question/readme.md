## 4. Reproduce immigration and extinction results 

Read Curtis et al. (2026), Probability, parameters, and duration of immigration and extinction in microbial communities. The ISME Journal 20, wrag195. Read the supplementary appendices and inspect the authors’ code 

1. Work in pairs with support from OpenAI Codex or Anthropic’s Claude. Explain the biological question and define the starting abundance, target abundance, birth and death probabilities, and time scale. 

2. Map the reported simulation and numerical results to their equations, parameters and boundary conditions. Reproduce them in stages: begin with the probability curves in Figure 1, then the duration calculations and the noise comparison in supplementary Figure A3. 

3. Use the supplementary material and authors’ code to check your implementation. Test the equal birth and death case and small populations. Record seeds for random runs and compare uncertainty as well as mean behaviour. 

4. Compare your plots with the published results using matching axes and units. Explain discrepancies before extending to the remaining simulation results. Each partner should run the code and explain how one result follows from the model. 

5. Keep runnable code, parameters and software versions (use Github or Bitbucket), reproduced plots beside their published targets, and a record of agreement and unresolved differences. 

6. For Exercises 4 and 5, save the useful AI prompts and identify AI-generated code. Check every equation, parameter and assumption against the paper. Record missing information explicitly; a plausible plot is not evidence that the published model has been reproduced.
