2 Plan the same reporter build in two tools 

Explore OpenCloning and the Benchling cloning tutorials
1. Find out what each tool does and follow an introductory example. Use the lecture reporter as your design 
brief. Select documented reporter and backbone sequences, record their sources and identify any differences 
from the lecture schematic.
2. In both tools, plan restriction/ligation, Golden Gate and Gibson assembly. For each route, show the starting 
DNA, required fragment preparation, joining steps and final annotated plasmid. Record any operation that 
requires a manual step.
3. Check insert orientation, part boundaries, internal restriction sites and the intended junction sequences. 
Identify how you would confirm the assembled DNA and then test reporter function.
4. Compare plans with another student using the same intended construct. Check whether both tools predict 
the same final sequence for each route. Resolve discrepancies and explain any junction differences between 
routes.

Keep the plans and plasmid maps from both tools, exported sequence files, and a short comparison of the three 
assembly routes
