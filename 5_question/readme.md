## 5. Reproduce the polymer clustering simulations 

Read Lui et al. (2013), Bacteria clustering by polymers induces the expression of quorum-sensing-controlled phenotypes. Nature Chemistry 5, 1058–1065. Read the supplementary information 

1. Work in pairs with support from OpenAI Codex or Anthropic’s Claude. Explain how polymer binding, bacterial clustering and signal transport could change quorum sensing. Separate the experimental measurements from the model predictions. 

2. Read the model description on supplementary pages S19–S24 and the simulated luminescence results on pages S26 to S30. Map the spatial rules, binding reactions, diffusion, growth and luminescence calculation to code and list the parameters and initial conditions. 

3. Reproduce the simulations in stages. Begin with one MM32 time course and its no-polymer comparison, then extend to the affinity comparisons and BB170 results. Match the reported conditions and averaging over independent runs; record the random seeds. 

4. Compare the trends, timing and magnitude with the published plots. Check ambiguous settings against the text and figure axes, and document any interpretation you make. Swap roles so each partner checks the model and reruns the analysis. 

5. Keep runnable code and a short README, the parameter sources, reproduced simulation plots and a clear account of discrepancies or missing details (use Github or Bitbucket).
